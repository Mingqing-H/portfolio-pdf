# 首页设计与开发方案：展开作品

更新日期：2026-10-28。状态：本地 V2 曲面展台完成；未发布。

## 真实目标与成功标准

让访问者在一个首屏内看懂「黄明清做什么」、看到真实作品、顺利进入具体案例或完整 PDF。设计感来自排版、真实内容、空间关系和克制的动效。首版完成响应式首页、作品索引、案例展开和关于信息；不增加未经提供的履历、客户评价、成绩或联系方式。

成功标准：桌面有明确视觉焦点；手机标题完整且无横向溢出；卡片能拖动、暂停、键盘操作并打开案例；减少动态效果模式静止；PDF 仅主动访问时请求；类型检查、生产构建、浏览器交互验证通过。

## 从 Reelmark 参考中提炼什么

| 参考 | 本站采用方式 | 原因 |
| --- | --- | --- |
| 浅薄荷背景、深绿、大标题 | 暖薄荷纸面 + 墨绿中文大字 | 与现有智慧景区作品呼应，同时衬托其他产品截图 |
| 弧形视频展台 | 真实作品全幅窗口，左右边独立变高，保持竖直 | 将作品作为主角，形成可探索的空间 |
| 手绘注释 | 一句「从想法到落地」与一条短箭头 | 增加人的痕迹，不堆装饰说明 |
| 十路同源视频 | 本地 WebP 静态截图 | 同源下载复用不等于解码开销消失；目前没有自己的视频素材 |
| 每帧重算裁剪和宽高 | 独立边高与动态超椭圆四边形裁剪 | 用户明确要求曲面保真；通过局部布局隔离与实测帧间隔控制开销 |
| 固定 1440×1080 画框 | 1440×1080 作为构图参考，实际使用响应式布局 | 保证笔记本、窄屏和手机文字可读 |
| 信任徽章、登录、注册 | 不采用 | 作品集没有这些业务需求，不编造社会证明 |

## 视觉系统

- 页面底色 #F5F8EF；正文 #101410；强调色 #08482D；次要文字 #626A60；分隔线 #DCE2D5。
- 作品截图铺满曲面窗口，底部用局部透明度渐变保障白色标题可读；移除外部彩色标题区，原图不加滤镜。
- 字体：中文系统无衬线（PingFang SC、Microsoft YaHei）；英文 Inter Tight 本地字体；不请求外部字体 CDN。
- 标题：桌面 clamp(52px, 6.1vw, 88px)，行高 1.15；手机 40–56px，行高 1.2；字距 -0.05em。
- 文本、按钮、图标均用真实 HTML / SVG；生成的概念图只用于构图参考，不充当网页截图背景。
- 所有圆角使用 superellipse(2)；不支持 corner-shape 的浏览器用采样超椭圆 polygon 裁剪。焦点环绘制在外层，避免被裁切。
- 轻阴影仅可用于截图层，外部作品卡不加厚重悬浮阴影。按钮、卡片与模态框共享形状规范。

## 页面与准确文案

首屏从上到下：
1. 顶栏：mq. / 黄明清；作品、关于；作品集 PDF。
2. 主标题两行：「把想法，做成」「真正可用的作品。」
3. 一行身份说明：「黄明清 · 产品设计、工具开发与 AI 实践」。
4. 「从想法到落地」手写批注及箭头；弧形作品展台。
5. 主按钮「浏览作品」，滚动至作品索引；展台有上一项、暂停/播放、下一项控制。
6. 首屏底边：SELECTED WORKS / 2026；产品 · 工具 · 数据。

下方为紧凑的作品索引（8 个真实作品，序号、标题、分类、进入箭头），不重复制作大卡片墙。点击索引或展台打开相同案例对话框。关于为简洁文字，依据 PDF 中产品、工具、数据及 AI 实践内容组织，无虚构履历。

案例对话框：准确项目标题、职责、问题与方案摘要、该页作品全图、打开对应 PDF 页入口。原始 PDF 为信息源；展台标题允许缩写，展开后保留原题。第 8 页配图继续注明功能示意。没有可核实的在线 demo 链接，不显示失效「体验」按钮。

## 组件与数据

React + Vite + TypeScript，npm 锁定依赖。App 组合 Header、Hero、WorkRail、WorkIndex、ProjectDialog、About；数据独立置于 src/content/projects.ts。
- src/content/projects.ts：id、原题、短题、分类、职责、摘要、颜色、PDF 页码、缩略图路径。
- public/works/：从仓库 PDF 提取的 WebP 小图及按需加载的大图。
- docs/portfolio.pdf：保留唯一原始副本；Vite 开发中提供同路径，构建时复制到 dist/portfolio.pdf。
- vite.config.ts：base=/portfolio-pdf/，站点资源均使用 BASE_URL。
- 不增加路由库、状态管理库、CMS 或后端。

## 交互与动效

- 入场使用 CSS 分层出现；展台延迟 320ms 后用 1.05s 从下方淡入并消退模糊，减少动态效果时关闭。
- 展台使用一个 Web Animations 长时钟与一个 requestAnimationFrame 循环；以时间差驱动 50×scale px/s 的自动移动。位置与速度存 ref，不逐帧触发 React render。
- 拖动与指针 1:1，释放速度指数衰减；超过 6px 判断为拖动，防止误开案例；保留触屏纵向滚动。
- 鼠标悬停继续自动移动；键盘焦点、打开案例、页面隐藏、展台离屏时停止自动移动。提供显式暂停，用户暂停后不自行恢复。
- 键盘左右键切换，卡片可 Tab/Enter 打开；焦点卡片移到展台中央，避免焦点藏在屏外。
- prefers-reduced-motion 下无入场、无自动移动、无惯性；手动切换即时完成。
- 对话框使用原生 dialog：焦点约束、Esc 关闭、关闭后回到触发位置；打开时锁定背景滚动。
- 不引入 Motion 仅为一次性淡入；后续有复杂布局转场时再加入。

## 性能预算与验收

- 首屏网络传输目标 ≤ 900KB（gzip JS/CSS + 可见作品图；不含用户主动打开的 PDF）。
- JS gzip ≤ 100KB，CSS gzip ≤ 15KB；首屏无视频、无 PDF 请求、无第三方字体请求。
- 全图仅在打开案例后加载；所有图像设置尺寸，避免布局偏移；离屏列表不重复下载大图。
- 桌面参考 1440×1080，同时验收 1366×768、390×844 与窄屏 320px。
- 本地测量布局稳定性、资源与主要交互；线上 LCP ≤ 2.5s / CLS ≤ 0.1 为后续发布目标，本地数据不代表微信或国内真实网络结果。
- 检查循环边界、指针取消、暂停持久性、减少动态效果、Tab/Enter/Esc、PDF 文件字节一致性和子路径资源。

### 几何与视觉

- 中心窗口基准 170×280；间距节距 196；宽度 170+48d²；中心外推 t×(1+0.083(t/r)²)。
- 左右边各自计算高度 280+92q^2.6；竖边直立，上下边随位置倾斜。中央紧凑，边缘外侧更高，完全取消 rotate。
- 使用 15 单位、n=4 的超椭圆转角采样生成四边形 clip-path；符合项目圆角规范。
- 1440×1080 下展台中心约 y=687；移动端按 640 单位缩放；较矮桌面按视口高度缩放。
- 作品截图 cover 铺满窗口，移除原来的大面积彩色标题区和内嵌截图框。底部保留简短作品名称和磨砂进入图标，保证案例可发现。
- 原作视频内容有独立运动；本站仍为用户 PDF 的静态作品截图，当前复刻窗口和滚动行为，不虚构项目演示视频。

### 运动与性能取舍

- Web Animations 长时钟 + 单 RAF，自动速度 50×scale px/s；悬停继续流动。
- 拖动改变逻辑横向位移；释放后附加速度以 0.05^dt 衰减，即每秒消退 95%，并继续基础自动滚动。
- 保留显式暂停、键盘焦点暂停、减少动态效果、弹窗暂停、页面隐藏及离屏停止。
- 为窄桌面和循环边缘使用两份相同作品序列，共 16 个 DOM 窗口；复本不进入 Tab 顺序与辅助技术内容。资源 URL 相同，不新增媒体请求。
- 曲面效果需要逐帧更新窗口宽高和 clip-path。将布局限制在 contain: layout style paint 内，跳过远离视口的窗口几何，不逐帧触发 React render。
- 清理 RAF 时同时取消长时钟，反复暂停/恢复后仍只有一个展台时钟。
