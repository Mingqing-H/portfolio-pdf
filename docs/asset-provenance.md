# 作品素材与内容来源

更新：2026-10-30。网站案例来自本人原版 PDF 与已授权的 GitHub 项目资料。未将 fork、镜像或资料备份计为独立原创项目；演示原型与实际工具在各案例中说明。

- `cover-*.webp`、`project-*.webp`：从本仓库 `docs/portfolio.pdf` 提取的原有材料，PDF 未修改。
- `research-weekly.webp`、`research-pool.webp`、`research-poolfit.webp`、`research-scenic-*.webp`：从同一 PDF 的嵌入原图重新导出。周报界面明确标示虚构演示数据。
- `research-trip.webp`：本人纸艺行程地图的真实界面；[在线作品](https://mingqing-h.github.io/MQ_trip-map/)。
- `research-rain.webp`：2026-10-30 截取的 [Heartfelt Rain](https://web-mq.vercel.app) 实际界面。仅预览图，不在作品集首页加载 WebGL 或音频。
- `research-muse.webp`：本人 [Muse-PI](https://github.com/Mingqing-H/Muse-PI) 前端的隔离空状态截图，未连接模型服务，不包含会话、文件或凭据。
- `research-engineering.webp`：本人 [工程工具公开预览](https://github.com/Mingqing-H/aggregation-platform-bosch-ETC-preview) 的工具中心界面。
- `scenic-demo.mp4`：本人景区项目原始演示录屏的 64–80 秒片段，裁去浏览器工具栏与字幕区域，H.264、24fps、1280×676、无声。画面为真实漫游、导览与灯谜互动，不含原录屏里的 AI 概念镜头。只有点击播放后请求。
- `scenic-video-poster.webp`：上面原录屏第 67 秒的实际画面。
- `social-preview.png`：本站真实页面截图，供分享卡片展示。
- `design/*concept.png`：内置 Imagegen 生成的版式参考，不参与网站生产展示。实际项目截图替换生成概念中的示意画面。

未将完整研究副本、原始 154MB 视频、业务输入文件、内部配置或数据库加入构建。原版 PDF 作为独立历史版本保留，不代表本次新增项目均已收入 PDF。
